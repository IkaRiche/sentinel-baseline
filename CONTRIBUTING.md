# Contributing

This repository contains documentation only. All files are licensed under CC BY 4.0.

## How to Contribute

- Fix typos or improve clarity
- Add translations
- Suggest additional patterns or anti-patterns
- Share anonymized incident learnings

## What NOT to Submit

- Operational code or scripts
- Platform-specific installation instructions
- Commands that could be copied and executed
- Anything that could enable spam or abuse
